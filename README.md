# AI School Timetable Studio — نظام إنشاء جداول الحصص المدرسية الذكي

نظام مجاني ومفتوح المصدر (Local-First) لإنشاء وتوزيع جداول الحصص المدرسية بضمان **0% تعارضات** (Zero Hard Conflicts)، يجمع بين:
- **محرك استمثال قيود رياضي حتمي (Deterministic Constraint Solver)** لفحص الجدوى وتوزيع الحصص مع احترام إجازات المعلمين، الحصص الأولى والأخيرة، والفترات المزدوجة.
- **وكيل جداول ذكي (AI Timetable Copilot)** يفهم اللهجات العربية (المصرية والخليجية والفصحى)، ويحدّث وثيقة المدرسة (`.md`) وهيكل البيانات والجدول تلقائياً.
- **نظام مفاتيح BYOK (Bring Your Own Key)** مع تدوير تلقائي للمفاتيح في المتصفح وتحويل سلس للمحرك المحلي الحتمي عند عدم وجود مفاتيح.
- **تصدير احترافي** إلى **PDF للطباعة (A3 العام + بطاقات الفصول والمعلمين A4)** و**Excel ملون (4 أوراق عمل)**، بالإضافة إلى **نسخ احتياطي واستعادة (JSON)**.

---

## المميزات الأساسية للخصوصية والأمان (Local-First & BYOK)
1. **بياناتك ومفاتيحك تبقى على جهازك**:
   - تُحفظ جميع بيانات المدارس والجداول محلياً في متصفحك (`localStorage`).
   - لا توجد قاعدة بيانات خادم ولا حسابات مستخدمين.
2. **مدير مفاتيح Gemini (BYOK) مع التدوير التلقائي**:
   - يمكنك إضافة مفتاح Gemini واحد أو عدة مفاتيح دفعة واحدة (سطر لكل مفتاح) من زر **`🔑 مفاتيح Gemini`** داخل الواجهة.
   - يعرض النظام آخر 4 خانات فقط من كل مفتاح (`••••XXXX`) ولا يسجل المفاتيح في أي سجلات (`logs`) أو رسائل خطأ.
   - عند تجاوز الحصة (`429`/`503`) يوضع المفتاح في فترة تبريد مؤقتة (`cooldown`) وينتقل النظام تلقائياً للمفتاح التالي؛ وعند فشل جميع المفاتيح أو عدم إضافة أي مفتاح، يستمر التطبيق في العمل فوراً عبر المحرك المحلي الحتمي.
   - **تنبيه الحصة (Quota)**: الحصة في Google AI Studio قد تُحسب على مستوى المشروع (`Project`)؛ للحصول على تدوير فعلي للحصص يُنصح بإنشاء كل مفتاح في مشروع مستقل.

## التشغيل المحلي (Run Locally)

**المتطلبات:** Node.js (الإصدار 20 أو أحدث)

1. تثبيت الحزم:
   ```bash
   npm install
   ```
2. تشغيل خادم التطوير:
   ```bash
   npm run dev
   ```
   ثم افتح المتصفح على `http://localhost:3000`.
3. فحص الأنواع والبناء والاختبارات:
   ```bash
   npm run lint
   npm run build
   npm test
   ```
